COZY GAME DAY POLISHED V16 💗

This is the polish pass on V15.

UPGRADED
• Separate top countdown retained and visually refined.
• Dashboard is now a true overview with Favorite Games, Live Now, On Your Services and Ranked CFB counts.
• Real Manage Favorites remains, now favorites-first and searchable.
• Favorite cards open full Team / Player Schedule pages.
• Team pages show next event, countdown, where-to-watch, up to 12 upcoming events and recent results.
• Team logos/headshots appear when ESPN supplies them.
• Game cards show college rankings and clearly invite tapping for details.
• Game-detail drawer retains watch info, venue, calendar, map, sharing and reminders.
• Prediction model upgraded: ranking edge + listed season-record edge + confidence wording + explanation bullets.
• Prediction probabilities are intentionally capped at 25–75 because the app does not have injury/lineup/market data.
• Family Game Day timeline retained.
• Home Screen/PWA polish improved with iPhone/iPad install guidance and manifest shortcuts.
• Calendar VALARM reminders remain the reliable Notification Center route without adding an external push service.
• Existing subscription matching, tennis, NFL standings, fixed MST, dark mode and celebration features retained.

IMPORTANT
True automatic Web Push while the app is closed still requires a persistent push-subscription backend and VAPID sender credentials. V16 does not fake that capability.
Weather still uses the real listed venue as a lookup rather than inventing a forecast. A dedicated weather API would be the next infrastructure addition.
