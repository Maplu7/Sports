COZY GAME DAY ULTRA V7 — ESPN ACCESS-DENIED FIX

WHY THIS VERSION EXISTS:
The Netlify health endpoint worked, but site.api.espn.com returned Akamai "Access Denied".
V7 changes the Netlify function to try:
1. site.web.api.espn.com
2. site.api.espn.com as fallback

It also uses a non-browser User-Agent and tests every feed on diagnostics.html.

UPLOAD/REPLACE ALL FILES IN YOUR GITHUB SPORTS REPO WITH THIS PACKAGE.

Required:
index.html
diagnostics.html
manifest.webmanifest
sw.js
icon-192.png
icon-512.png
netlify.toml
netlify/functions/sports.js

AFTER NETLIFY DEPLOYS:
1. Open /api/sports?feed=health
   It should say service: cozy-game-day-sports-v7
2. Open /api/sports?feed=nfl
   It should return JSON with events, NOT an Access Denied page.
3. Open /diagnostics.html
   It checks NFL, college football, ATP, WTA, and standings separately.
4. Open the main tracker and press Refresh now.

If the Home Screen app is stale, open the website in Safari and refresh once, then reopen the Home Screen app.
